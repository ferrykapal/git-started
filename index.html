Using a Mac or Linux?

Open the Terminal app instead of PowerShell. The git commands are the same. Differences: open index.html in any text editor (such as VS Code) instead of Notepad, and preview it with open index.html (Mac) or xdg-open index.html (Linux). To sign in before your first push, run gh auth login (needs the GitHub CLI), or paste a personal access token when Git asks for a password (see Stuck? below).

Good to know: other .html files

Every .html file in your repo gets its own address. A file called about.html would live at your-username.github.io/git-started/about.html. index.html is just the one shown at the main address.

The loop

The loop you’ll repeat forever

edit files → git add . → git commit -m "msg" → git push

Add picks what goes in the snapshot. Commit saves it with a message. Push uploads it. git status is your best friend in between.

Branches: your safe sandbox

A branch is a copy of your project where you can try things without breaking main. Happy with it? Merge it back. Not happy? Delete it and nothing happened.

What it looks like

main is what your live site shows, so it stays safe while you experiment.

Stuck? It happens to everyone

fatal: not a git repository

You’re in the wrong folder. Run pwd and ls , then cd into your project.

Authentication failed / password not accepted

GitHub doesn’t take your account password for pushes. On Windows, run git push again and finish the sign-in window that pops up. On Mac/Linux, run gh auth login , or (fallback) create a personal access token (GitHub Settings → Developer settings) and paste it when Git asks for a password. Nothing shows while you paste. That’s normal.

'git' is not recognized

PowerShell can’t find Git. Close PowerShell and open a fresh one (it only notices a new install after a restart). Still stuck? Git may not be installed yet, so ask a helper.

Please tell me who you are

Git needs a name once: git config --global user.name "Your Name" and git config --global user.email "you@example.com" .

Pages shows a 404

Give it a minute. Check Settings → Pages is set to main / root, and that your file is named exactly index.html .
